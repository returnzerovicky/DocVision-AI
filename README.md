# 📄 DocVision AI

AI-powered Document Intelligence System for OCR, Document Understanding, Layout Analysis, Identity Document Parsing, and Information Extraction using Vision Transformers.

## Features

- OCR
- Invoice Parsing
- Receipt Parsing
- Passport Parsing
- Aadhaar OCR
- PAN OCR
- Table Detection
- Layout Detection
- Signature Detection
- Named Entity Extraction

## AI Models

- TrOCR
- Donut
- LayoutLMv3
- EasyOCR
- Tesseract OCR

## Tech Stack

- Python
- PyTorch
- Hugging Face Transformers
- OpenCV
- EasyOCR
- Tesseract
- Streamlit
